#+title: Emacs elisp reference

- Everything is a list or atom
- First item = function/macro
- Prefix notation:

#+begin_src elisp
(+ 1 2)
(message "Hello")
(setq x 10)
#+end_src

* Evaluation

| Command | Meaning         |
|---------+-----------------|
| C-x C-e | Eval last sexp  |
| C-M-x   | Eval defun      |
| M-:     | Eval expression |
| M-x     | Run command     |

Examples:

#+begin_src elisp
(+ 2 3)
(length "hello")
(buffer-name)
#+end_src

* Variables

** Set global:
#+begin_src elisp
(setq my/value 42)
(setq my/name "Miguel")
#+end_src

** Local:
#+begin_src elisp
(let ((x 10)
      (y 20))
  (+ x y))
#+end_src

** Sequential:
#+begin_src elisp
(let* ((x 10)
       (y (+ x 5)))
  y)
#+end_src

* Functions

** Basic:
#+begin_src elisp
(defun my/hello ()
  "Say hello."
  (message "Hello!"))
#+end_src

** With arguments:
#+begin_src elisp
(defun my/add (a b)
  "Add A and B."
  (+ a b))
#+end_src

** Interactive command:
#+begin_src elisp
(defun my/greet (name)
  "Ask for NAME and greet."
  (interactive "sName: ")
  (message "Hello %s" name))
#+end_src

* Interactive Codes

| Code | Meaning          |
|------+------------------|
| s    | String           |
| n    | Number           |
| f    | File             |
| d    | Current point    |
| r    | Region start/end |

Examples:

#+begin_src elisp
(interactive "sName: ")
(interactive "nNumber: ")
(interactive "fFile: ")
(interactive "r")
#+end_src

* Conditionals

** if:
#+begin_src elisp
(if (> x 5)
    (message "Big")
  (message "Small"))
#+end_src

** when:
#+begin_src elisp
(when (> x 5)
  (message "Big"))
#+end_src

** unless:
#+begin_src elisp
(unless (= x 0)
  (message "Not zero"))
#+end_src

** cond:
#+begin_src elisp
(cond
 ((> x 10) "large")
 ((> x 5)  "medium")
 (t        "small"))
#+end_src

* Truth

- nil = false
- everything else = true

#+begin_src elisp
(if "" "true" "false") ;; true
(if 0 "true" "false")  ;; true
#+end_src

* Loops

** while:
#+begin_src elisp
(let ((i 0))
  (while (< i 5)
    (message "i=%d" i)
    (setq i (1+ i))))
#+end_src

** dolist:
#+begin_src elisp
(dolist (x '(1 2 3))
  (message "%s" x))
#+end_src

* Strings

#+begin_src elisp
(concat "Hello " "World")
(format "%s = %d" "Age" 30)
(length "Hello")
(substring "Hello" 0 2)
#+end_src

* Lists

#+begin_src elisp
(setq my/list '(a b c))
(car my/list)   ;; first
(cdr my/list)   ;; rest
(nth 1 my/list) ;; second
(push 'z my/list)
#+end_src

* alist (association list)

#+begin_src elisp
(setq my/alist '((csharp-mode . csharp-ts-mode)
                 (python-mode . python-ts-mode)))

(assoc 'csharp-mode my/alist)
#+end_src

* Patterns

** Prefix map:
#+begin_src elisp
(defvar my/dotnet-map
  (let ((map (make-sparse-keymap)))
    (define-key map (kbd "b") #'my/dotnet-build-root)
    map))

(global-set-key (kbd "C-c d") my/dotnet-map)
#+end_src

** Conditional by mode:
#+begin_src elisp
(cond
 ((derived-mode-p 'python-mode) "# ")
 ((derived-mode-p 'csharp-ts-mode) "// ")
 (t "// "))
#+end_src

** Use current mode comment:
#+begin_src elisp
(or comment-start "// ")
#+end_src
