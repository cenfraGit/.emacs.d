#+title: emacs cheatsheet
#+startup: overview

opens read-only with =C-c h c=, =C-x C-q= to edit it.
tab on a heading folds/unfolds it. shift-tab cycles the whole file.
forgot a key? type the prefix (like =C-c d= or =C-x p=) and wait, which-key
lists everything under it.

** dotnet menu (=C-c d=)
| key           | does                                                |
|---------------+-----------------------------------------------------|
| =-c=          | pick Release / Debug (press again to clear)         |
| =-n=          | --no-restore, saves ~1s when packages didn't change |
| =-b=          | --no-build, run/test only, just start what's built  |
| =-w=          | hide compiler warnings (build, test, run)           |
| =-p=          | include pre-release (package search and install)    |
| =b r= / =b p= | build solution root / pick a project                |
| =c r= / =c p= | clean root / project                                |
| =t r= / =t p= | test root / project                                 |
| =r p=         | run a project (each in its own buffer)              |
| =n=           | new project or solution, added to nearest .sln      |
| =a= / =d=     | add / remove project reference                      |
| =p=           | search nuget and add a package                      |
| =C-x s=       | (inside the menu) save current options as default   |

in a compilation buffer: =C-c C-k= stops it, =g= reruns it, =RET= on an
error jumps to it, =M-g n= / =M-g p= walks through errors from anywhere.

* buffers and windows
a buffer is an open thing (file, compilation, magit...). a window is a
split showing one buffer. closing a window doesn't close the buffer.

| key                  | does                                           |
|----------------------+------------------------------------------------|
| =C-x b=              | switch buffer (consult, live preview)          |
| =C-x k=              | kill (close) buffer                            |
| =C-x <left>/<right>= | previous / next buffer in this window          |
| =C-x C-b=            | ibuffer, see below                             |
| =C-x p b=            | switch to a buffer of the current project only |
| =C-x p k=            | kill all buffers of the current project        |
| =C-x 2= / =C-x 3=    | split below / right                            |
| =C-x o=              | jump to other window                           |
| =C-x 0= / =C-x 1=    | close this window / close all others           |
| =C-x 4 b=, =C-x 4 f= | buffer / file in the other window              |

** ibuffer (=C-x C-b=)
a buffer list you can act on. mark buffers, then do something to all of them.
| key           | does                                          |
|---------------+-----------------------------------------------|
| =RET= / =o=   | open buffer / open in other window            |
| =m= / =u=     | mark / unmark                                 |
| =U=           | unmark all                                    |
| =d= then =x=  | flag for closing, then close all flagged      |
| =D=           | close marked buffers right away               |
| =S=           | save marked buffers                           |
| =* M=         | mark all buffers of a mode (like csharp-mode) |
| =% n=         | mark by name regexp                           |
| =/ n=         | filter by name                                |
| =/ m=         | filter by mode                                |
| =/ /=         | remove filters                                |
| =s a= / =s m= | sort by name / by mode                        |
| =g=           | refresh                                       |
| =q=           | quit                                          |

** narrowing in =C-x b=
type the letter and a space first. recent files also show up below the
buffers without narrowing.
| prefix  | shows                              |
|---------+------------------------------------|
| =p SPC= | only the current project           |
| =f SPC= | recently opened files (last 100)   |
| =b SPC= | buffers                            |
| =* SPC= | modified (unsaved) buffers         |
| =m SPC= | bookmarks                          |
| =SPC=   | hidden buffers (like =*Messages*=) |

* files and projects
a project is a git repo (or a folder with a .sln/.csproj, via cslite).

| key       | does                                             |
|-----------+--------------------------------------------------|
| =C-x p p= | switch project, then pick what to do             |
| =C-x p f= | find file in project (fuzzy, ignores gitignored) |
| =C-x p g= | search text in project                           |
| =C-x p d= | open a folder of the project in dired            |
| =C-x p c= | compile in project root                          |
| =C-x p != | run a shell command in project root              |
| =C-x p e= | eshell in project root                           |
| =C-x C-f= | find file anywhere                               |
| =C-x C-j= | dired at the current file's folder               |

orderless: in any prompt, space separated pieces match in any order.
=cont ser= finds =src/Services/UserController.cs=. pieces must be real
substrings, =ctrl= won't match =Controller=.

** dired (file manager)
=RET= open, =^= up, =+= new folder, =C= copy, =R= rename/move, =D= delete
(to trash), =m= mark, =u= unmark, =g= refresh.

* tabs
emacs has two kinds of tabs, easy to mix up:
- *tab-bar* (=C-x t=): each tab is a whole window layout, like a
  workspace. this is the useful one.
- tab-line: per-window list of buffers, like browser tabs. not set up.

the bar shows up when there are 2+ tabs. tabs are numbered
(=tab-bar-tab-hints=).

| key         | does                                            |
|-------------+-------------------------------------------------|
| =C-x t 2=   | new tab, opens on the home screen               |
| =C-x t 0=   | close tab                                       |
| =C-x t o=   | next tab (=C-TAB= too, once the bar is showing) |
| =C-x t O=   | previous tab                                    |
| =C-x t RET= | switch tab by name                              |
| =C-x t r=   | rename tab                                      |
| =C-x t m=   | move tab                                        |
| =C-x t u=   | reopen last closed tab                          |
| =C-x t b=   | open a buffer in a new tab                      |
| =C-x t f=   | open a file in a new tab                        |
| =C-x t t=   | run the next command in a new tab               |

** a workflow that works
one tab per project:
1. =C-x t t C-x p p= opens a project in a new tab
2. =C-x t r= name it after the project
3. inside, =C-x p b= only shows that project's buffers
4. =C-x t RET= jumps between projects by name

or one tab per task in the same project, like "code" with the source
split, and "run" with the compilation buffers.

* marks, registers and bookmarks
three ways to get back to a place, from short-lived to permanent.

** marks
the mark is the other end of the region. emacs also keeps the last 16
in a ring per buffer, plus one global ring across buffers. many jumps
leave a mark behind on their own (=M-<=, =M->=, =C-s=, =M-.=, search
results...), so you can usually go back without having set one.

| key           | does                                              |
|---------------+---------------------------------------------------|
| =C-SPC C-SPC= | leave a mark here without selecting anything      |
| =C-u C-SPC=   | jump back to the last mark in this buffer         |
| =C-SPC= again | (right after) keep going back through older marks |
| =C-x C-SPC=   | jump back to the last mark in any buffer          |
| =C-x C-x=     | swap point and mark (also reselects the region)   |
| =M-g m=       | list marks in this buffer, live preview (consult) |
| =M-g k=       | list marks in all buffers (consult)               |

** registers
named slots, one letter or digit each. gone when emacs closes.

| key           | does                                                    |
|---------------+---------------------------------------------------------|
| =C-x r SPC a= | save this position in register =a=                      |
| =C-x r j a=   | jump to register =a=                                    |
| =C-x r s a=   | copy the region into =a=                                |
| =C-x r i a=   | insert the text from =a=                                |
| =C-x r w a=   | save the window layout in =a= (=C-x r j a= restores it) |
| =C-x r n a=   | put a number in =a=                                     |
| =C-x r + a=   | add to the number in =a=                                |

** bookmarks
like registers for positions, but saved, so they survive restarts.
| key       | does                                  |
|-----------+---------------------------------------|
| =C-x r m= | set a bookmark here (asks for a name) |
| =C-x r b= | jump to a bookmark                    |
| =C-x r l= | list, rename and delete bookmarks     |
| =m SPC=   | in =C-x b=, only bookmarks            |

|--------------------+---------------------------------------------------------|
| =<f3>= / =<f4>=    | record a keyboard macro / stop, then =<f4>= replays it  |
| =C-u 10 <f4>=      | replay the macro 10 times (=C-u 0 <f4>= until it fails) |

| =C-x n d=          | narrow to the current function                          |
| =C-x n w=          | widen, show everything again                            |
| =M-s .=            | search for the symbol at point                          |
| =M-s h r= / =h u=  | highlight a regexp in the buffer / remove it            |
| =C-x 4 c=          | second view of the same buffer, can be narrowed apart   |
